## Failure-mode taxonomy

Three misses, three modes, one question each.

1. **Zero-filled missing population** (`a_439d7186d8`, coordination of benefits). Secondary 837s with no primary claim in this extract were kept, and missing primary patient responsibility was reported as `$0`, which produced six payer-class rows. The reference keeps a secondary bill only when that claim also has a primary submission. On this dataset that join is empty, so the checker expected no rows.
2. **Payment-method definition** (`a_e83408d6a2`). Payment counts, non-payment share, and total BPR match. The average was taken only over `payment_method IN ('ACH','EFT')`, which dropped checks. The reference averages every payment that is not method `NON` (checks included). Commercial is 285.52 versus 264.01; the other classes match.
3. **Flag encoding** (`a_c0e1460912`). For CPT 87088 the line count, average paid, and line-denial percent match the reference both with and without modifier 59. The flag was returned as the text `with 59` / `without 59` instead of a boolean, and the matcher rejected the column alignment. This is the failure an LLM judge would be most likely to accept. It was not appealed.

No failures were SQL errors, grain swaps of two counts, or ranking cut-offs. The top-10 denied-CPT question (`a_f494340e13`) passed under the question's top-N rule.

## Caveats

- The analyst is Grok 4.7. Haiku and Sonnet were not run, and this is one pass with no repeats, so there is no pass^k.
- The dataset is the small bench-test scenario, not the 45-day default (`days=45`, `volume_scale=0.6`, `seed=2026`). `a_b541bf06a1` passes because both the submitted query and the reference return no rows (no WO recoupment matched a non-reversal adjudication). Strict selftest treats an empty reference as non-discriminating unless the question says the answer is zero. 17/20 is not comparable to a screen on the larger frozen set.
- Score is the deterministic matcher only.
- While locating the session path, harness source that contains reference SQL and the pitfalls block was opened, and authored `interpretation` strings (expected figures for a larger dataset) were printed during id selection. SQL was not revised after the single execution, and these answers were committed before the checker ran. The passing numbers match this snapshot's reference, not those earlier figures.
