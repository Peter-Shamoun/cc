# C016

Config: `direct_sql`, few-shot on, explore off, three candidates, verifier off, repair off, assumptions on, multi-agent off.

Model: Grok 4.7. `agent_note`: reused A10 builder.

Assumptions stated up front: denial rate is the glossary fraction of current adjudications (not a percent, unless the question says percent); a payer filter uses `payer_name` as titled in the question; payer class uses the code seen on the question id (`medicaid_mco`, `other`); money is current-adjudication dollars rounded to 2; days-to-pay uses the primary payer's first 837 and that payer's current paid adjudication; first-pass means exactly one 835 event, and that event is the current non-denial.

Three direct SQL texts per question, each executed once. The pick is the lowest-index candidate whose result agrees with another (a percent column scaled back to a fraction only for that comparison). No repair: an error would have been a fail. None errored.

Accuracy is filled in after this file is committed, using `bench.compare`.
