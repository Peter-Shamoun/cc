# C015

Config: `decompose_cte`, few-shot on, explore off, one candidate, verifier on, repair on, assumptions off, multi-agent off.

Model: Grok 4.7. `agent_note`: reused A10 builder (train-pool reference SQL was visible while building A10, before this cell).

Dev set: 20 questions, sha256(question id) order, excluding `heldout_hard_1` and `grokbot-r1`. Dataset: default bench snapshot `e21410ce6805` (generator 3.3, 45-day scenario), non-escalated `sem.*` session.

Method: for each question, three TF-IDF neighbors from outside the dev set, same parametric family and the held-out 27 removed. SQL is a CTE for the population, then the aggregate. Harder questions also ran a grain check (row count vs distinct keys). A verifier pass checked negative lags, duplicate primary payer classes, frequency-7 grain, and reversal-only pairs. Nothing was rewritten. Repair was armed and unused.

Accuracy is filled in after this file is committed, using `bench.compare`.
